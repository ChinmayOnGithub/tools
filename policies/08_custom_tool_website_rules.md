# Custom Rulebook for Utility & Tool Websites

In addition to Google's official policies, AI reviewers and platform validators should enforce the following quality rules specifically tailored for online tools and web applications to prevent "Low Value Content" rejections:

---

## Key Enforcement Rules

1. **Tool Context & Explanation:**
   - Every tool page must clearly explain what the tool does, how it works, and who it is for.

2. **Practical Examples:**
   - Provide concrete, practical input and output examples or step-by-step usage instructions.

3. **Comprehensive FAQs:**
   - Include a dedicated FAQ section addressing common questions, edge cases, data privacy/security (e.g. client-side processing), and troubleshooting.

4. **Related Tools & Navigation:**
   - Interlink to related tools, categories, and parent directory pages to ensure proper site structure and user navigation.

5. **Unique Page Metadata:**
   - Every single tool page must have unique `<title>`, meta description, canonical URL, and structured data tags—avoiding duplicate SEO metadata across tools.

6. **Boilerplate Minimization:**
   - Avoid duplicate introductions, identical descriptions across similar tools, or generic low-effort filler text.

7. **Actionable & Value-Added Guidance:**
   - Provide genuinely useful advice, context, and capabilities beyond the bare interactive control itself.
